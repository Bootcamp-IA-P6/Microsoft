# ADR-034: Documentation language: team agreement not stakeholder-approval theater

- **Date:** 2026-07-20
- **Author:** Mirae Kang
- **Status:** Accepted
- **Components affected:** Decision log wording

## 1. Context

Draft docs used phrases like “stakeholder approval” / “PO approval” that were inaccurate or unnecessary.

## 2. Alternatives Considered

- **A — Keep approval theater labels:** Looks formal; misleading.
- **B — Prefer “team agreement” / final decision only; do not narrate PO approval chains:** Accurate.

## 3. Decision

Adopt **B**.

## 4. Consequences

- **Pros:** Honest decision log.
- **Cons:** None material.

- None at time of writing.
